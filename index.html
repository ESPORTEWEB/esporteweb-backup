EsporteWeb Backup Rclone

Informações sobre a integração de cópias de segurança do Sistema Esporte Web com o Google Drive.

Para que serve

Esta integração administrativa utiliza o Rclone e a API do Google Drive para armazenar cópias de segurança do Sistema Esporte Web, com a finalidade de facilitar a recuperação em caso de falha do computador ou do banco de dados.

O banco de dados operacional é mantido separadamente no servidor autorizado. O Google Drive é usado como destino de cópias de segurança, não como servidor PostgreSQL.

Privacidade e segurança

A configuração planejada prevê backups criptografados antes do envio e acesso restrito às pastas e aos arquivos criados pela integração, utilizando o escopo drive.file do Google Drive.

A rotina de envio com dados reais só deverá ser ativada após testes de criptografia, restauração e autorização institucional.

Leia a Política de Privacidade e Uso dos Dados.

Quem utiliza

Ferramenta de uso administrativo restrito, destinada à operação autorizada do projeto Sistema Esporte Web da Usina da Paz Terra Firme. Não é um aplicativo público de inscrição, matrícula ou consulta de alunos.
